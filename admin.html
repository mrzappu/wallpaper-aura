Google Cloud Console Configuration Guide
  1. Go to Google Cloud Console.
  2. Create a project (e.g. Wallpaper Aura).
  3. Go to APIs & Services → OAuth consent screen → fill details.
  4. Go to Credentials → Create Credentials → OAuth Client ID (Web Application).
  5. Under Authorized JavaScript origins, add:
    https://wallpaper-aura.vercel.app and http://localhost:3000.
  6. Save your generated Client ID and Client Secret here.
